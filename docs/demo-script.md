# Demo script (about 6 minutes)

**Before the demo** (same machine, on the venue's power and audio setup): run `tools/demo-prep.sh`. It builds the Release app, runs the self-tests, regenerates the fallback session and prints what the audio device reports. Launch with `open build-release/OpenSession_artefacts/Release/OpenSession.app`. Set input gain so the track meter peaks around −12 dBFS (the first smoke take clipped at 0 dBFS). Have a terminal open at the repo for step 10.

Prepared fallback: `demo/DemoSession.osession` is generated by `OpenSession --make-demo` and contains only synthesised audio we own (plucked-string, bass, drum and formant tones). Say so when you open it. The live part uses the real microphone/interface.

1. **Setup (45 s).** Audio > Audio Settings. Point at: device, 48 kHz, buffer frames and ms, driver-reported latency, the manual adjustment field, the loopback measure button. Say: buffer time is not round-trip latency; we show all three numbers.
2. **Arm guitar (30 s).** New session. Track 1: input = Input 1, press R. Show the input meter moving. MON = OFF: "you hear yourself through the interface, not through us, zero added latency". Flip to AUTO to show software monitoring.
3. **Record to click (45 s).** Click on, Count-in on (optional: Transport > Click only while recording, so playback stays clean), press Rec. One bar of click, then play 8 bars. Stop. Clip appears with the waveform drawn from the file; status line shows the file name, length, bit depth.
4. **Overdub (45 s).** Track 2: input = Input 2 (or the same mic), R. Rec from the start: Track 1 plays, click plays, you record a vocal. Stop. Open `Audio/` in Finder: two WAVs, named by track and time.
5. **Takes (30 s).** Rewind, Rec again on Track 2. Stop. Take lane shows take 1 muted below take 2 active. Double-click take 1: it becomes active, take 2 mutes. Nothing was deleted.
6. **Edit (30 s).** Split at playhead (Cmd+T), trim an edge, drag a fade, Cmd+Z. Show the file in Finder is unchanged.
7. **Mix (30 s).** Cmd+M mixer: fader, pan, EQ and compressor on the vocal, reverb on master; FX... opens the parameter editor.
8. **Save/reopen (30 s).** Cmd+S. Quit, relaunch, open the `.osession` folder (or drag the folder to another location first). Everything is back.
9. **Export (30 s).** File > Export stereo mix → open the WAV in QuickTime. File > Export stems → show equal-length files starting at 0:00; the report shows peak levels and any clipping. The tail after the last clip (default 2 s) is under File > Export tail after last clip.
10. **Evidence (45 s).** Terminal: `build-release/OpenSession_artefacts/Release/OpenSession.app/Contents/MacOS/OpenSession --run-tests` (34 cases, ~25 s). Show `docs/test-results.md` hardware table, `docs/recording-behavior.md` (documented vs product-chosen), `docs/cost-and-competition.md` prices, `LICENSE` + `THIRD_PARTY_NOTICES.md`.

If live recording fails: File > Open demo session, say it is synthesised, and continue from step 5.
